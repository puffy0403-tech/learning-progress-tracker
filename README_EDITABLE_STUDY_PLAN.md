# LearnPilot 可編輯讀書計畫

## 新增功能
- AI Study Plan 頁新增「手動建立讀書計畫」，不需 AI Key 或學習目標即可使用。
- 可新增、刪除排程列，編輯日期、科目／學習項目、學習內容、預計分鐘。
- 星期依日期自動計算；一份計畫限同一週，跨週請另建。
- 「開始另一份手動計畫」開啟新草稿；同草稿重複儲存更新原紀錄。
- AI／規則備援產生後可先編輯再儲存，保留原有分析與建議。
- 我的下週學習日曆可選取已儲存計畫並修改，使用 UPDATE 更新原 plans.id。
- 日曆使用資料庫 week_start，歷史計畫不會被移到目前的下週。
- 儲存失敗會顯示錯誤並保留表單內容。更新會比對原內容，避免覆蓋其他分頁修改。

不需要 migration。原始 supabase_setup.sql 已具 plans 的 SELECT / INSERT / UPDATE
本人 RLS policy 與 authenticated 權限。現有專案不必重跑 setup。
全新資料庫才依 README_SUPABASE.txt 執行原 supabase_setup.sql。
本次未連線、更改你的正式資料庫。

仍使用 plans(id, user_id, week_start, content, created_at)。
content 保留可閱讀的 Markdown，尾端加 HTML comment 包含版本化 JSON，
精確保存日期、分鐘、多行內容及備註；不新增欄位、不回填或刪除舊資料。
舊文字計畫開啟時解析為排程，未辨識文字保留在可編輯備註，確認儲存後才寫入新版格式。
遇到不規則的舊文字，請確認排程列並手動補足；可在日曆展開原文核對。
user_id 由目前登入者取得，查詢與更新皆限制本人，並維持原 RLS。
不用也不應改用 service role key。
